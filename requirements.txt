# PixelRAG demo 依赖清单
# 已验证环境：macOS / Apple Silicon M1 Pro 32GB / Python 3.12.15（conda 环境名 pixelrag）
#
# 安装：
#   conda create -n pixelrag python=3.12 -y
#   conda activate pixelrag
#   pip install --no-compile -r requirements.txt
#
# 两个注意点：
#   1. 加 --no-compile 是为了不生成 .pyc，避免安全中心的批量删除保护误拦
#      （pip 清理临时文件时单轮删除数会超过 50）。
#   2. pdf2image 依赖系统组件 poppler，需先 brew install poppler。
#
# pixelrag 的 extras：index=索引与检索，pdf=PDF 渲染，serve=查询服务。
# 本项目实际只用 index + pdf；serve 在 macOS 上加载模型时段错误，已弃用
# （见《PixelRAG快速启动指南.md》附录踩坑记录）。
